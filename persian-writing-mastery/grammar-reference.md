# مرجع دستور زبان و نگارش فارسی

این فایل را وقتی جزئیات بیشتری لازم است بخوان؛ برای کار روزمره همان `SKILL.md` کافی است.

## ساختار جمله

ترتیب رایج: نهاد + (مفعول/متمم) + فعل.

| ضعیف (ترتیب انگلیسی) | طبیعی |
|----------------------|--------|
| ما نیاز داریم به تنظیم کردن سرور | باید سرور را تنظیم کنیم |
| این اجازه می‌دهد کاربران را که… | این کار به کاربران اجازه می‌دهد… |
| برای بهبود پرفورمنس ما استفاده می‌کنیم از کش | برای بهبود عملکرد از کش استفاده می‌کنیم |

## هماهنگی نهاد و فعل

- جمع با فعل جمع: «توسعه‌دهنده‌ها می‌نویسند»
- جمع مکسر/اسم جمع با فعل متناسب با معنا: «مردم می‌آیند»
- در لحن محاوره‌ای «میان»/«می‌کنن» فقط اگر کاربر صریحاً محاوره خواسته باشد

## کاربرد «را»

| درست | نادرست / مبهم |
|------|----------------|
| فایل را باز کن | فایل باز کن (اگر مفعول مشخص است) |
| نتیجه را بررسی کردیم | نتیجه بررسی کردیم |
| به سرور وصل شو | سرور را وصل شو (حرف اضافه اشتباه) |

«را» را روی هر اسمی نچسبان؛ فقط وقتی مفعول مستقیم مشخص است.

## نیم‌فاصله — جدول مرجع

| نوع | درست | نادرست |
|-----|------|--------|
| پیشوند فعلی «می» | می‌نویسم | می نویسم / مینویسم |
| نفی | نمی‌توانم | نمی توانم / نمیتوانم |
| به‌ + اسم | به‌صورت، به‌عنوان، به‌کارگیری | به صورت*، بعنوان، بکارگیری |
| ترکیب‌های اسمی رایج | برنامه‌نویسی، توسعه‌دهنده، سیستم‌عامل | برنامه نویسی، توسعه دهنده |
| جمع با «ها» در بسیاری از موارد | داده‌ها، پروژه‌ها، آن‌ها | داده ها، پروژه ها، آنها |
| پسوند «ی» نسبت وقتی لازم | ایرانی، نرم‌افزاری | نرم افزاری |

\* در برخی سبک‌های قدیمی «به صورت» با فاصلهٔ کامل دیده می‌شود؛ در این Skill نیم‌فاصلهٔ «به‌صورت» ترجیح داده می‌شود مگر سبک پروژه خلافش را بگوید.

## علائم نگارشی

| علامت | کاربرد |
|-------|--------|
| . | پایان جمله |
| ، | مکث کوتاه بین اجزا |
| ؛ | جدایی دو جملهٔ مرتبط |
| : | پیش از توضیح یا فهرست |
| ؟ | پرسش |
| ! | تأکید یا تعجب (کم استفاده کن) |
| «» | نقل‌قول و نام‌گذاری در نثر فارسی |
| () | توضیح فرعی؛ زیاده‌روی نکن |

فاصله: قبل از ، ؛ : ؟ ! فاصله نگذار؛ بعدشان یک فاصله بگذار.
نقطه و ویرگول به واژهٔ قبلی می‌چسبند.

## رسمی در برابر محاوره

| رسمی | نیمه‌رسمی | محاوره‌ای |
|------|-----------|-----------|
| خواهشمند است بررسی فرمایید | لطفاً بررسی کنید | یه نگاهی بنداز |
| این امر منجر به… می‌گردد | این کار باعث… می‌شود | اینجوری … می‌شه |
| کاربران محترم | شما / کاربر | تو (فقط اگر مناسب است) |

بدون درخواست کاربر، متن را عامیانه نکن. بدون نیاز، متن را «می‌نماید» هم نکن.

## دام‌های ترجمه تحت‌اللفظی

| تحت‌اللفظی | طبیعی |
|------------|--------|
| آن را آسان می‌کند برای مدیریت | مدیریت را آسان‌تر می‌کند |
| مطمئن شوید که که… | مطمئن شوید که… |
| در ترتیب برای اینکه | برای اینکه / تا |
| تیک د باکس را | تیک جعبه را بزن / گزینه را فعال کن |
| بر اساس روی | بر اساس |
| لوریج کردن قابلیت | از این قابلیت استفاده کن / بهره‌برداری کن |

## اصطلاحات فنی — نگه دار

API، SDK، CLI، CI/CD، Docker، Kubernetes، PostgreSQL، Redis، Next.js، React، TypeScript، Python، Git، GitHub، Cursor، Linux، Ubuntu، JWT، OAuth، webhook، endpoint، commit، deploy، pipeline
